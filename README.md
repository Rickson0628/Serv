# Serv

Serv is a two-sided vehicle services marketplace connecting customers with local automotive service providers. The goal is to make it easier for customers to discover reliable services while giving professionals a place to showcase their work and reach new customers.

## About the Project

Serv is designed around two account types:

- **Customers:** Can explore vehicle service categories and, as development progresses, discover providers and book services.
- **Service Providers:** Can create an account, manage a provider profile, and eventually connect with customers through the platform.

The current project focuses on automotive services such as:

- Mechanical Repair
- Auto Detailing
- Body Work
- Windshield Repair
